## 一、什么是"乐高大电影感"

《乐高大电影》并非真实定格动画，而是 Animal Logic 用超过 2000 种数字积木件渲染的 CG 动画，刻意模拟玩家 brickfilm（积木定格短片）质感：**拉帧**（每 2-4 帧才更新画面）制造顿挫感，积木件带划痕、指纹、灰尘的"被使用感"。它把爱好者美学提升到好莱坞级别。五条视觉特征及提示词抓手：

| 特征 | 含义 | 提示词抓手（英/中） |
|------|------|---------------------|
| 一切皆积木 | 场景、道具、特效全部由真实乐高颗粒拼搭 | built entirely from real LEGO bricks / 全部由真实乐高积木拼搭 |
| 标准乐高人仔 | 圆柱黄头+C形钩手+方块躯干+印刷脸 | classic LEGO minifigures / 标准乐高人仔 |
| 塑料使用痕迹 | ABS 塑料质感带划痕指纹，"被玩过" | realistic ABS plastic texture with subtle scratches and fingerprints / ABS塑料质感带细微划痕指纹 |
| 凸点颗粒 | 每个表面积木凸点清晰可见 | visible studs on every surface / 凸点颗粒清晰可见 |
| 微缩电影感 | 电影级布光+浅景深+移轴微缩感，非平面插画 | cinematic lighting, shallow depth of field miniature photography / 电影级布光浅景深微缩摄影 |

**风格坐标（内部参照系）：**

| 经典形态 | 视觉路线 | 与本 skill 关系 |
|----------|----------|-----------------|
| 乐高大电影 1/2 | 电影感布光 + 伪定格 + 积木特效 | **默认主线最接近的坐标** |
| 乐高官方产品摄影 | 纯白背景 + 柔光棚拍 | 子风格模块（§九） |
| 收藏展示盒 | 玻璃立方 + 博物馆铭牌底座 | 子风格模块（§九，源自用户参考文件） |
| 官方说明书海报 | 三段式版式 + 步骤编号 | 子风格模块（§九，源自用户参考文件） |

## 二、风格块（三级 + 硬约束层）

> **设计总纲（2026-09 定版）**：上美影版的核心纪律是"平涂"（禁阴影渐变3D），乐高版**完全相反**——需要塑料体积感、写实光影与景深。因此乐高版硬约束的打击对象是：**手绘感、2D扁平化、非积木的光滑几何体、写实人体**。两条姊妹 skill 的风格块不可互相套用。

**中文为本 skill 的默认提示词语言**（即梦/Seedream/豆包均为中文语境）。`[本剧色盘中文]` 替换为 §三 声明的剧组色盘。**结尾强命令不可删**：

### 2.3 精简版（Seedance 视频提示词首行专用）

**v1 配方（定版）**。与图片端的分工：图片端负责"真实积木质感"锚定，视频端负责"伪定格节奏+电影运镜"锚定。**首行风格行逐集逐字相同**（仅氛围词不同），防风格漂移：


**v1 设计要点：**
1. 品牌用"乐高大电影"全称锚定动画语境，区别于静态产品照；
2. 正向词组"真实乐高积木微缩场景 + 标准乐高人仔造型"双锚定，分别压场景端与人偶端；
3. "伪定格动画节奏"是视频端独有关键词——提示模型拉帧顿挫，防止动得太顺滑变成普通CG；
4. 否定词只打击真敌（手绘/2D平涂/非积木几何体），**不禁阴影禁景深**——那是乐高感的组成部分。

## 四、造型设计规范（人仔规范）

乐高造型与写实短剧审美**直接相反**，与姊妹 skill 的"概括造型"呼应但工具不同——上美影靠手绘概括，乐高靠**件式拼搭**：

| 维度 | 规则（乐高人仔） |
|------|------------------|
| 体型 | 一律标准乐高人仔：头部+躯干+腿部三段式，整体约 4 段高；**禁止写实人体比例** |
| 头部 | 圆柱形黄色头部，顶部一个凸点；默认黄色肤色（乐高种族中立传统）； licensed 写实肤色仅限用户点名 |
| 脸 | 印刷表情脸：经典点状眼+微笑；按角色配置不同印刷件（怒脸/皱眉/獠牙反派脸/花痴笑/闭目） |
| 发饰 | 头发/帽子为**一体式乐高发件或帽件**：古装束发件、斗笠件、头盔件、王冠件等；**禁止写实发丝** |
| 躯干 | 方块躯干，服装细节为**躯干印刷图案**（衣纹、铠甲、腰带、纹样全部印刷），不是真实布料 |
| 手 | C形钩手；手持物必须是对应**乐高配件件**（剑件、锄头件、书卷件、伞件），比例与人仔匹配 |
| 腿 | 标准短腿件；孩童用短腿件（legs short）；坐姿=腿前伸一体件 |
| 辨识度 | 每个角色声明**专属主色 + 专属印刷纹样 + 专属发件/帽件**（写进人物小传视觉形象栏），三人同框不撞脸 |
| 反派 | 允许装饰性丑化：獠牙怒脸印刷件、黑暗色系件、疤痕印刷，但保持玩具趣味，不做恶心化 |
| 老人 | 白发件/白眉毛印刷+皱纹印刷脸 |
| 儿童 | 短腿人仔（整体更矮）+ 大号印刷脸 |
| 异兽/神怪 | 砖砌积木兽（brick-built beast，由基础颗粒拼出兽形轮廓）或官方动物模具件；**神性标记**对位为：珍珠金部件、透明件发光部位、专属印刷纹样之一；形体概括可读，远看剪影可识别 |

## 六、构图原则（写画面描述时贯彻）

1. **微缩感优先**：高机位俯拍+浅景深营造 diorama 感，或人仔视角低机位仰拍显宏大——两极镜头是乐高电影的标志性语法；
2. **底板意识**：场景立于乐高底板（baseplate）上，远景/俯拍可让底板边缘入画，强化"这是一个乐高世界"的元趣味；特写镜头可省略；
3. **凸点入画**：中近景必须能读到凸点颗粒；大特写以凸点阵列做前景细节；
4. **大色块拼接**：画面由乐高官方色大块面拼接分割（如：主体亮红 + 远景亮绿底板 + 天空纯白）；
5. **效果积木化**：水火烟云光一律按 §C 速查表用积木/透明件表达，禁止真实流体/粒子特效；
6. **使用痕迹**：光描述可带"划痕指纹在光线下隐约可见"，增加"被玩过的玩具世界"质感；禁止"柔光光晕、梦幻滤镜"等插画化词。

## 七、Seedance 视频端风格注入

1. **首行固定**：每集提示词第一行 = §2.3 精简版风格行 + 本剧色盘简写 + 时长/画幅/氛围。除"氛围"词外，风格行**逐集逐字相同**——防风格漂移的硬机制。子风格剧按 §2.3 变体表替换媒介质感词。
2. **正文风格强化**：风格不能只押首行。每个时间段落（0-3秒/3-6秒/…）的描述中**至少自然嵌入一个风格词**：积木颗粒、凸点、拼搭、人仔、塑料质感、透明件、底板、伪定格、砖砌等，写进主体或动作描述里。
3. **动作写"顿挫"**：动作描述强调"一顿一顿""逐格移动""拼搭式变化"——呼应伪定格拉帧；转场可写"积木拆解重组式转场"（乐高电影标志性手法：场景/角色以散件飞入拼装完成）。
4. **参考图画风锁定**：【参考】行末尾必须加画风锁定语："严格保持参考图片的乐高积木画风与色盘"（子风格剧替换为对应画风名，如"博物馆展盒画风""说明书海报画风"）。Seedance 能从参考图锚定画风，但需要显式要求。
5. **尾帧描述带风格**：每集尾帧描述必须包含色盘与至少一个风格词，保证下一集接力不丢风格。
6. **资产引用**：`@图片X` 引用 C/S/P 资产图；角色一致性靠 C01 标准像 + 四视图（人仔部件图），场景一致性靠三机位图。
7. **拼搭式开场（E01 浓度）**：E01 的风格浓度要最高，可在 0-3 秒写"散落积木件腾空拼搭成场景"的开场拼装镜头——乐高电影标志性开场语法，E01 定调即全剧定调。

## 八、叙事与声音适配

### 8.1 旁白体制

## 十二、风格置换工作流（上美影 → 乐高 Remix）

**第 2 步：色盘置换。** 按下表映射并在新素材清单头部重新声明：

|----------|-----------|
| 青瓷绿 | 亮绿（场景）/ 中绿 |

**第 3 步：造型置换。** 人物小传"视觉形象"栏按 §四人仔规范重写：真人特征 → 人仔三件套（印刷表情脸 + 一体发件/帽件 + 躯干印刷服装）；"专属纹样"→"专属印刷纹样"；异兽"神性标记"→ 珍珠金部件/透明件发光部位。头身比映射：成人5-7头身→标准人仔，孩童3-4头身→短腿人仔，异兽→砖砌积木兽。

**Remix 自检：** 原项目自检清单中的"平涂/水墨"项全部失效，改跑本 skill 的质量自检清单。
